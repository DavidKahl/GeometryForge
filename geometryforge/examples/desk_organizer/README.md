# Configurable desk organizer

Default: 120 × 70 × 40 mm, three compartments, 2.4 mm walls/floor. Edit parameters.json through your agent. Blender preserves cavity Boolean modifiers; Houdini preserves the equivalent Boolean SOP networks.

Print upright with the floor on the bed. No supports are intended. Validate the generated mesh and review it in your slicer. The functional check measures compartment cross sections and actual solid volume. This example has been digitally verified, not physically printed.
