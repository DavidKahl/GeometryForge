# Print evidence

Collect bed dimensions and nozzle size; use explicit example defaults only when the user accepts them. Outputs are millimeter STL/3MF, not sliced jobs or G-code.

Generic checks cover watertightness, winding, positive volume, shell count, dimensions and bed fit, followed by export readback. Author functional checks for actual cavities, mating parts, minimum walls and clearances. Material assignment metadata is a slicer extension and may require manual assignment in other slicers.

Keep assembly coordinates for inspection and separate print orientations. Provide assembly notes, support expectations and a coupon cut from or derived consistently with actual interfaces. A SAFE POINT means recorded checks passed; physical fit depends on material, printer and slicing. Do not claim a model was printed unless a physical print was observed.
