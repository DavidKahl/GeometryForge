# Native game integration fixtures

`blender.py` covers a three-meter modular doorway with three separate convex collision bodies, a procedurally displaced 20,480-triangle Nanite rock, a printable 2 mm shell/0.2 mm fit coupon, and a game derivative of the retained legacy organizer. `checks.py` measures actual geometry: the doorway traversal path must remain outside every collision hull, and rays through the shell/coupon measure walls, floor and clearance.

These are disposable integration cases, not generic modeling logic or promises of physical manufacturability.
