# Reference provenance

The project follows the user's wall/component photographs and reactor concept
board in the conversation. Original attachments were not available as local files.

- PSU: BRIMETI 24 V 200 W, supplied drawing 178 × 50 × 24 mm.
  https://www.amazon.de/dp/B0BRP3ZDJF
- Controller: MiBoxer FUT039S; user's measured envelope is used.
  https://www.amazon.de/dp/B0953NR4P1
- Strip connector accessory link supplied by the user:
  https://www.amazon.de/dp/B0DTV2ZZS3
- Distribution connectors: user specifies three-way Wago 221;
  221-413 is the accepted mechanical assumption.
  https://www.wago.com/at/installationsklemmen/verbindungsklemme-mit-hebeln/p/221-413

The design borrows the reactor reference's segmented circular face and removable
cover arrangement. The optional Y-shaped insert is a playful Flux Capacitor homage,
not a replica or a powered lighting feature.
